**Daily Building Permit Leads for Contractors in Arizona**

Real-time high-value construction leads (Roofing • Solar • HVAC • Remodeling • Additions • Commercial) for Tucson/Pima County and Phoenix/Maricopa County.

Live Dashboard: [https://arizonapermitpulse-ywqioednez3qgkevrfxjeu.streamlit.app/](https://arizonapermitpulse-ywqioednez3qgkevrfxjeu.streamlit.app/)

## 🚀 Quick Start (Local)

```bash
# 1. Clone the repo
git clone https://github.com/domleon2/ArizonaPermitPulse.git
cd ArizonaPermitPulse

# 2. Install requirements
pip install streamlit pandas requests pdfplumber

# 3. Run the scraper
python real_scraper.py

# 4. Launch dashboard
streamlit run main.py
